# Group Generators for Latin Square Orbit Computation

## Problem Statement

Given a set of isotopy class representatives of Latin squares of order *n*, compute the
full orbit (closure) under row permutations, column permutations, and symbol permutations,
where each result is reduced (first row normalized to the identity).

## Definitions

A **Latin square** of order *n* is an *n × n* array filled with *n* different symbols,
each occurring exactly once in each row and each column.

The **symmetric group** S_n is the group of all permutations of {0, 1, ..., n−1}.
Its order (size) is |S_n| = n!.

An **isotopy** of a Latin square is a triple (α, β, γ) ∈ S_n × S_n × S_n that permutes
the rows by α, columns by β, and symbols by γ. Two squares related by an isotopy are
**isotopic** and belong to the same **isotopy class**.

A **reduced** (or **row-reduced**) Latin square has its first row equal to the identity
permutation (0, 1, 2, ..., n−1). Any Latin square can be reduced by permuting its columns
so that the first row becomes the identity.

## The Orbit Computation

Starting from isotopy class representatives, we want to find all distinct reduced Latin
squares reachable by independently permuting rows, columns, and symbols.

The group acting on the squares is:

$$G = S_n^{\text{row}} \times S_n^{\text{col}} \times S_n^{\text{sym}}$$

For each square L and each (α, β, γ) ∈ G, we compute the image and reduce it.
The **orbit** of L under G (modulo reduction) is the set of all distinct reduced squares
obtainable this way.

## Naive Approach

Apply all |G| = (n!)^3 group elements. Since row and symbol permutations are applied
independently and reduction handles column normalization, the implementation typically
applies all n! row permutations, all n! column permutations, and all n! symbol permutations
separately, reducing after each. This gives 3 × n! operations per square.

For order 6: 3 × 720 = 2,160 operations per square.

## Generator-Based Approach

### Key Theorem

**Theorem (Cayley, 1849).** The symmetric group S_n is generated by the set of adjacent
transpositions:

$$S_n = \langle \tau_1, \tau_2, \ldots, \tau_{n-1} \rangle$$

where τ_i = (i−1, i) is the transposition swapping elements i−1 and i.

**Proof sketch.** Any permutation can be written as a product of transpositions. Any
transposition (a, b) with a < b can be decomposed as:

$$(a, b) = \tau_{a+1} \cdot \tau_{a+2} \cdots \tau_{b-1} \cdot \tau_b \cdot \tau_{b-1} \cdots \tau_{a+2} \cdot \tau_{a+1}$$

Therefore the adjacent transpositions generate all transpositions, which generate all of S_n. ∎

### Alternative Generating Sets

Other minimal generating sets for S_n include:

1. **Single transposition + n-cycle:** S_n = ⟨(0, 1), (0, 1, 2, ..., n−1)⟩
2. **All transpositions involving a fixed element:** S_n = ⟨(0, 1), (0, 2), ..., (0, n−1)⟩

The adjacent transpositions are preferred because:
- Each generator is a simple swap of two adjacent elements
- Row/column swaps are O(n); symbol swaps are O(n²)
- The number of generators is n−1 (minimal for transposition-based generation)

### Application to Orbit Computation

Since S_n = ⟨τ_1, ..., τ_{n-1}⟩, the orbit of a square under S_n (acting on rows) can be
computed by repeatedly applying just these n−1 generators rather than all n! permutations.

The full generating set for G = S_n^row × S_n^col × S_n^sym is:

$$\{ \tau_i^{\text{row}}, \tau_i^{\text{col}}, \tau_i^{\text{sym}} \mid i = 1, \ldots, n-1 \}$$

This gives **3(n−1) generators** in total.

### BFS Orbit Algorithm

```
Input: set of isotopy class representatives R
Output: set of all distinct reduced squares in the orbits of R

queue ← R
seen ← R

while queue is not empty:
    L ← dequeue(queue)
    for i = 0 to n−2:
        for each action in {swap_rows(i, i+1), swap_cols(i, i+1), swap_symbols(i, i+1)}:
            L' ← action(L)
            L'' ← reduce(L')
            if L'' ∉ seen:
                seen ← seen ∪ {L''}
                enqueue(queue, L'')

return seen
```

### Correctness

The BFS explores the Cayley graph of G with the chosen generators. Since the generators
produce all of S_n through composition, every element of the orbit is reachable through
some path of generator applications. The BFS is guaranteed to find all such elements
because:

1. Every permutation π ∈ S_n can be expressed as a product of adjacent transpositions
2. Applying π to a square L is equivalent to applying its transposition decomposition sequentially
3. Each intermediate result is a valid square that will be discovered and processed by the BFS
4. The reduction step canonicalizes each square, ensuring consistent deduplication

### Complexity Comparison

| | Operations per square | Total ops (N unique squares) |
|---|---|---|
| All permutations | 3n! | 3n! × N |
| Generators | 3(n−1) | 3(n−1) × N |
| **Ratio** | **n!/(n−1) = n · (n−2)!** | |

| Order n | n! | n−1 | Speedup factor |
|---------|-----|-----|----------------|
| 4 | 24 | 3 | 8× |
| 5 | 120 | 4 | 30× |
| 6 | 720 | 5 | 144× |
| 7 | 5040 | 6 | 840× |
| 8 | 40320 | 7 | 5760× |
| 9 | 362880 | 8 | 45360× |
| 10 | 3628800 | 9 | 403200× |

The speedup grows super-exponentially, making the generator approach essential for
higher orders.

### Trade-off: More BFS Iterations

The generator approach discovers fewer new squares per processing step (at most 3(n−1)
neighbors vs. 3n! with all permutations). This means the BFS takes more iterations
(more batches) before the orbit is fully explored. However, each iteration is dramatically
cheaper, and the total work (summed across all iterations) is lower because every unique
square is processed exactly once regardless of approach.

## Verified Results

For order 5 with 2 isotopy class representatives:
- All-permutations approach: **1,344 reduced squares**
- Generator approach: **1,344 reduced squares**
- The sets are identical (verified by sorted comparison).
